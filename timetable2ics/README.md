# 课程表转日历（timetable2ics）

把 CSV 格式的课程表转换成 .ics 日历文件，导入手机后自动按周重复。

## 问题

每学期开学，20 门课要手动输进手机日历，花 1 小时还容易输错时间和教室。

## 方案

用 Python 读取 CSV 课程表，以学期第一周的周一为基准，按"星期 + 时间"
算出每门课的具体日期，用 RRULE 生成 16 周重复的事件，输出标准 .ics 文件。

## 结果

- 从手动输入 1 小时，变成生成 + 导入 10 秒
- 改课只需改 CSV 重新生成
- 课程数量不限

## 用法

1. 编辑 courses.csv，填入自己的课程
2. 修改 main.py 里的 BASE_MONDAY 为学期第一周的周一
3. 运行 `py main.py`
4. 用日历应用打开生成的 courses.ics

## 技术栈

Python 3 · csv · datetime
